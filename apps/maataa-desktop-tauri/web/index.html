Spacecraft Navigation Utility

Offline heliocentric trajectory simulator · Hemant time display

SIMULATION · NO FLIGHT CONTROL

This is a software simulation using a Sun-only gravity model and a synthetic starting state. It does not read spacecraft sensors, determine a real vehicle's position, or send commands. Flight use requires mission data, qualified hardware, independent validation, and mission approval.

Scenario inputs

Heliocentric inertial position in kilometres and velocity in kilometres per second.

Integrator: fixed-step RK4, two-body Newtonian gravity, Sun as the sole central body. No perturbations, relativistic corrections, sensor fusion, or uncertainty propagation.
