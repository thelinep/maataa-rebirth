# Maataa UI — full reference package

Product-agnostic React 19 UI layer with a 17-module registry, host contracts, evidence and approval boundaries, responsive workspace, themes and standalone static demo.

- `packages/ui/src/`: package source.
- `apps/demo/index.html`: open directly to explore the 17 screens.
- `docs/INTEGRATION.md`: host boundary and example.
- `docs/STATUS.md`: implemented and unconfigured capabilities.
- `docs/ARCHITECTURE.md`, `docs/CANONICAL_REGISTRY.md`: foundation documents.

Run `pnpm install --frozen-lockfile` and `pnpm check`.

This is a reference package, not a production release. No real AI, voice or approval actions are invoked.
