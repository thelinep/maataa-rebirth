# Generated package snapshots

The JSON files in this directory describe the package API, registries, demo data, identity/icon catalogues, and release preparation. Regenerate the supported snapshots with `pnpm prepack`; the bundle report is refreshed by `pnpm bundle:check`.

`SOURCE_INVENTORY.json` and `SHA256SUMS.txt` are preserved historical snapshots from before the folder reorganization. Their recorded paths reflect that earlier layout and they are not current-tree integrity evidence. `CONSUMER_CERTIFICATION.json` and `BUNDLE_REPORT.json` are also retained records; use a fresh consumer or bundle run for current evidence.
