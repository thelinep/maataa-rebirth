# MAATAA UI Public / Demo Surface — Alpha 7.4

Alpha 7.4 ships a complete local Vite host with eight hash-routed surfaces:

- `#/` — landing page
- `#/surface` — three-pane live registry explorer with visual preview canvas and copy actions
- `#/playground` — interactive component/layout responsive playground
- `#/sandbox` — safe isolated composition sandbox with JSON + generated JSX
- `#/demos` — deterministic Redux scenario hub
- `#/docs` — documentation with copyable code examples
- `#/help` — help center
- `#/support` — local-only support composer with copyable ticket text

## Live Surface

The Full Surface route is no longer a text-only catalog. It has a catalog pane, live visual canvas, and inspector/code pane. Components/atoms render interactive package-owned specimens; layouts/pages/workspaces/devices/generators/tools/AI spaces/registries/state catalogs render dedicated visual previews. Canonical IDs, import paths, and generated snippets have copy controls.

## Playground

The Playground renders real `Button`, `Input`, `Card`, `Badge`, and `Tabs` components. Theme, density, radius, and viewport width are interactive. Current source and settings can be copied.

## Sandbox

The Sandbox safely composes approved blocks without evaluating arbitrary code. Users can add/remove blocks, edit/apply JSON, and copy the resulting JSON or generated JSX.

All runtime authority remains host-owned; these surfaces are deterministic local demos.

## Identity / Icon catalogs

Full Surface now includes dedicated **Identities** and **Icons** catalogs with live visual previews, stable IDs and copyable import examples.
