# Type system

Alpha 7 introduces shared types under `@maataa/ui/types`.

Canonical registry identifiers are inferred directly from the existing `as const` registries for page, workspace, layout, device, generator, tool, AI space, and registry IDs. Domain-neutral shared types cover async status, lifecycle/verification status, navigation, device simulation, AI messages/agents/models/evaluations, demo entities, and Redux slice contracts.
