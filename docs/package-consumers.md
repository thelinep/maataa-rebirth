# Packed package consumer qualification

`pnpm package:consumer` builds and packs the actual package, installs that tarball in fresh Vite and Next.js App Router fixtures, then runs strict TypeScript and production builds. Plain Node imports test the root, composer and runtime entry points without bundler resolution. The Next.js fixture is a small consumer application: the root layout imports package CSS and wraps the application with `UiProvider`/`ThemeToggle`; its public home page introduces the shared React package; and `/workflow` demonstrates a NEVO event-planning slice with three synthetic event fixtures, a public browser-local brief, an operator run-of-show preview, and a review snapshot. The journey stops before authenticated tenant handoff and explicitly shows that no quote is sent, booking/hold is created, or payment, guest, or vendor action occurs. Its static export is checked for both routes and rendered content, and a Playwright browser journey exercises the built export at desktop and mobile sizes.

The emitted ESM finalizer resolves every relative static or dynamic import against an actual emitted JavaScript file. It refuses missing targets and preserves user-generated code strings. Compiler source-map comments are removed because rewritten offsets invalidate them. React TSX implementation entry points receive a preserved `use client` directive; pure TypeScript specification/registry modules remain usable on the server.

Next.js 16.3.8 is pinned in the fixture, using React 19, alongside a packed Vite React 18.2 minimum-peer fixture. This is a tested candidate matrix, not a claim that every declared peer version has been qualified. Plain SSR imports also run in an isolated Node 20.0.0 minimum runtime. Other Next versions and full minimum-Node toolchain runs require separate evidence. The NEVO workflow is illustrative local state only: it is not an authenticated pilot, persistence layer, tenant handoff, or production integration. Its data and event dates are synthetic planning examples. After `pnpm package:consumer`, use `pnpm consumer:next:preview` to view the exported Next consumer locally. A PASS report proves this bounded consumer exercise for the run that produced it; it does not establish exact-commit release certification by itself.
