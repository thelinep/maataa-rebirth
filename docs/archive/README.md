# Archived local analysis

Generated Alpha 8.6 and Alpha 8.7 bundle, compatibility, and composition analysis files are kept under `.certification/analysis-history/` by version. These are local, ignored working artifacts rather than canonical source or release evidence.

Current product references are grouped under `docs/product/`, release planning under `docs/release/`, and generated package snapshots under `manifests/`. The package metadata and manifest generators have been updated for those paths. The root keeps the package entry README and the tool configuration files expected by the current build commands.
