# Package provenance

This artifact extends the prior standalone atomic MAATAA UI source package with the layout, page, workspace and registry taxonomies defined during the MAATAA UI architecture session.

The package is intentionally UI-only. Catalog entries for identity, API, runtime, infrastructure, database, governance and release concepts are vocabulary/integration metadata unless a source module explicitly implements a visual component. They are not claims that operational runtimes exist.


## Alpha 5

Generator, tool and AI-space taxonomies were added from the explicitly enumerated MAATAA catalog in this conversation. They are design-system vocabulary, not claims that corresponding runtime services are implemented.

- Alpha 6 device vocabulary is derived from the MAATAA device taxonomy established in this conversation; it is a UI/registry model, not hardware certification.
