# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest `1.0.0-alpha` / `beta` prerelease | Yes |
| Older prereleases | No |

## Reporting a vulnerability

Please report suspected vulnerabilities privately, not in public issues:

- **Route:** `<GitHub private vulnerability reporting link or monitored security mailbox>`

Include the affected version, a description, reproduction steps and the impact you expect.

## What to expect

- Acknowledgement within **3 business days**.
- An initial assessment within **7 days**.
- A fix or mitigation for high or critical issues targeted within **30 days**; other issues in the next minor release.
- Credit in the release notes if you wish.

## Scope

This policy covers the `@maataa/ui` package. Applications in this repository that are outside the release scope (for example Hemant Observatory, MAATAA Desktop shells, Support Center) are not covered by it.
